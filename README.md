# Introduction to Linux

Проект по анализу вакансий Data Scientist с HeadHunter.

## Структура
- `src/ex00` – загрузка вакансий в JSON
- `src/ex01` – конвертация JSON → CSV
- `src/ex02` – сортировка CSV
- `src/ex03` – очистка названий вакансий
- `src/ex04` – подсчёт уникальных позиций
- `src/ex05` – партицирование и конкатенация по датам

## Запуск
Каждый скрипт запускается из своей папки командой `./имя_скрипта.sh`.
